# 断点接续 · 经典浮窗

面向 **macOS＋Codex** 用户，在桌面找回任务停点，并返回原对话继续。

> [!IMPORTANT]
> **当前 v0.1.2 仍是源码预览版，需要开发工具。**
> 尚未提供可直接安装的 App／DMG、Agent 接线包或首次连接向导。打开浮窗不会自动整理你的任务；这些是下一版目标，尚未完成。

**[当前如何试用](docs/INSTALL.md) · [源码 Release](https://github.com/Dep-0302/resume-desk/releases/tag/v0.1.2) · [下一版计划](docs/ROADMAP.md)**

## 最低交付标准

**用户只需把本仓库链接交给 Agent，由 Agent 完成安装、接入用户自己的 Codex 记录，并验证浮窗正常使用。** 用户只处理必要授权和环境缺项，不需要自行编译、填写 JSON 或寻找测试入口。

当前只有手动试用指引，这条完整流程尚未实现并通过验收。DMG 是后续体验提升，不是完成最低标准的前提。

## 现在能做什么

- 按项目显示已核对的回顾，悬停查看“上次／停点／下一步”。
- 点击返回原任务；勾选表示接手，叉号经确认后停止关注。
- 已有恢复后端支持扫描、导入、报告与提醒判定；真实内容仍需 Agent 核对并写入。

## 你该从哪里开始

| 你的目标 | 当前入口 |
|---|---|
| 把仓库链接交给 Agent 完成安装和真实接入 | 这是最低交付标准，目前尚未达标；见[计划](docs/ROADMAP.md) |
| 下载后直接使用，不操作终端 | 当前还不支持；请查看[普通用户版计划](docs/ROADMAP.md) |
| 愿意参与源码试用 | 按[试用步骤](docs/INSTALL.md)构建，并让 Codex 完成首次真实回顾 |
| 开发或验证界面 | 查看[开发说明](docs/DEVELOPMENT.md)；测试数据不代表真实接入成功 |

**看到“隔离任务”“正文可点击，从这段文字继续”时，显示的是测试数据。** 正常首次使用没有回顾时应为空；不要把 QA 窗口当作已连接自己的任务。

优先完成：**交给 Agent 仓库链接 → 安装 → 真实回顾 → 正常使用**；之后再提供直接下载安装体验。范围仍为经典浮窗与必需的恢复能力，不纳入另一套未完成 App。
