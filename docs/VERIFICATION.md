# 经典浮窗发布验证

本版本只验证 01A 恢复后端和 01B 经典浮窗；未完成独立 App 的检查不再计入发布结果。

| 入口 | 核对内容 |
|---|---|
| `scripts/check.sh` | 87 项 Python 回归、唯一浮窗构建、搬移后的随包后端读写及源码/包内容检查 |
| `scripts/check-native.sh` | 20 项拖动事件回放、10 类悬停/导航检查、两轮自适应屏幕的布局与位置恢复 |
| `scripts/check-release.py` | 允许的源码范围、唯一 App、版本与 macOS 14 目标、内嵌后端字节一致、无个人路径或运行状态 |

测试只使用临时合成任务，不操作个人队列。测试需要 macOS 图形会话；受限沙盒看不到显示器时不能记为界面通过。

保留了已验证的旧 SDK 编译适配和原生文字高度测量修复。列表按现行“一行停点＋悬停全文”核对；窗口位置在当前显示器可见范围内恢复。

实际物理鼠标体验、全屏/跨桌面及使用效果仍需要使用者验证。源码公开不等于已签名的 App 下载包或用户验收。每次提交的线上结果以 GitHub Actions 为准。
