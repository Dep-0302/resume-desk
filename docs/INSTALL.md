# 当前如何试用

**当前为源码预览，需要命令行和开发工具；还没有双击安装版。** 可安装的 App、Agent 接线包和首次连接向导见[计划](ROADMAP.md)。

## 1. 准备并构建

需要 macOS 14+、可运行的 Codex、本机 Apple 命令行工具（`xcrun swiftc` 和 `/usr/bin/python3`）。缺少工具时先完成官方安装，不要通过运行测试脚本代替环境准备。

下载[最新源码](https://github.com/Dep-0302/resume-desk/releases/tag/v0.1.2)，解压后在仓库目录运行：

```sh
zsh build.sh
```

产物为 `dist/断点复原浮窗.app`。**构建成功只代表 App 可启动，还没有接入你的真实回顾。**

## 2. 让 Codex 完成首次真实回顾

在 Codex 中打开这个源码目录，可以粘贴下面这段要求。它是手动试用指引，尚不是已发布的 Skill：

> 请按本仓库 docs/RECOVERY.md 帮我完成首次真实回顾。先检查环境，并向我确认是否允许只读扫描本机 Codex 记录；取得确认后，再按当前接口扫描、核对真实停点，并将有原文依据、真实会话 ID 和当前指纹的回顾导入后端。不要把普通已答问答都当待办。运行文件和中间结果放在用户数据目录，保留已有状态，不写进 Git 仓库。向我展示结果和覆盖缺口，再打开正式浮窗。不要生成演示任务，不运行 QA 窗口，不修改原对话，也不设置定时任务或登录项。

需要完成的是：**扫描 → Agent 核对 → 校验并导入 → 生成回顾 → 展示**。只执行 `scan` 或打开 App 都不能替代中间的核对。

默认数据目录：`~/Library/Application Support/ResumeDesk/Recovery`。核对使用你自己的 Codex 账号和额度；内容由 Codex 按你的账号设置处理。

## 3. 打开并核对

保持 Codex 运行，然后执行：

```sh
open 'dist/断点复原浮窗.app'
```

应看到自己的项目、原任务标题和具体停点；点击应返回对应原对话。勾选仅表示接手，不代表业务完成。退出入口在菜单栏图标中。

| 看到的情况 | 下一步 |
|---|---|
| 列表为空 | 检查是否已生成并导入首份回顾；也可能确实没有待接续事项 |
| “隔离任务”或重复测试文案 | 这是测试状态；退出测试窗口，让 Codex 核对启动路径和 `--state-dir`，不要删除真实状态 |
| 没出现窗口 | 检查 Codex 是否运行；当前浮窗随 Codex 显示 |
| 构建、读取或授权失败 | 保留具体错误；不要据此判断“没有任务” |

当前不会自动安装每日回顾或后台服务；定时触发需要另外设置。完整首次接入的普通用户体验仍待验证。
