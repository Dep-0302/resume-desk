# 后续计划

首发范围为 **macOS＋Codex 桌面版的经典浮窗与恢复后端**。

| 状态 | 内容 |
|---|---|
| v0.2.0 已实现 | 仓库内 Agent 入口与 Skill、环境检查、按版本安装、只读来源导出、逐条核对、整批校验导入、后端与显示验证 |
| 待真实用户验证 | 不同干净 Mac 的首次安装、权限提示、长会话覆盖和日常使用体验 |
| 后续 | 自带运行环境、首次连接向导、Developer ID 签名与公证的安装包、便捷更新与卸载 |
| 按用户选择 | 全局 Skill／插件分发、定时回顾；当前不自动安装或开启 |

最低入口已是“把仓库链接交给 Agent”。DMG 是后续体验提升，当前仍需要开发工具。验证不以预置假任务替代真实接入；发布范围不含另一套未完成 App。
